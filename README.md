# Algorithms

Codewars kata and algorithm practice, 2021–2023, one file per problem, grouped by
language.

| Folder | Files | Notes |
|---|---|---|
| `javascript/` | 110 | The bulk of it. Mostly Codewars 8kyu–5kyu, plus a few classic implementations (merge sort, insertion sort, memoized Fibonacci, a singly linked list). |
| `java/` | 16 | The same katas redone in Java while learning the language. |
| `typescript/` | 9 | First TypeScript, compiled with the included `tsconfig.json`. |

Each file is self-contained: open it, read the problem in the comment at the top where
there is one, and run it with `node`, `javac`/`java`, or `tsc`.

This repo merges four earlier practice repos (`AlgoWarz`, `AlgoWarz2`, `JSalgos`,
`TSalgos`) with the duplicates between them removed. The same problem solved in two
languages is kept in both.
